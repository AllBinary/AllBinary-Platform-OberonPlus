                             AllBinary Platform Oberon+

What is it?

This repository contains code generated by the AllBinary Platform for support in Oberon+.  
This repo is used to allow developers to skip the Oberon+ code generation step.

What are some example games with this Oberon+ code?

https://allbinary.itch.io (The downloads with "-oberon" in the filename are Oberon+ only builds. Currently that only includes nothing. Also the Oberon+ builds are not available on Google Play or other stores.)
